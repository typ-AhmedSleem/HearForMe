**Foundation Colors:**

- **Primary:** A calming, accessible blue (e.g., #2196F3) for key actions and branding.
- **Accent:** A vibrant, eye-catching color (e.g., #FFC107) for alerts and important highlights.
- **Text (Primary):** Dark grey (e.g., #212121) for high readability.
- **Text (Secondary):** Medium grey (e.g., #757575) for less critical information.
- **Background (Light):** Pure white (e.g., #FFFFFF) for clean main backgrounds.
- **Background (Subtle):** Very light grey (e.g., #F5F5F5) for secondary background elements or cards.
- **Error:** Red (e.g., #F44336) for critical warnings.

**Typography:**

- **Font Family:** A clean, sans-serif font like Roboto or Lato for excellent readability.
- **Headlines (e.g., H1 - App Name):** Bold, 28pt.
- **Titles (e.g., H2 - Screen Titles):** Semi-bold, 22pt.
- **Subtitles (e.g., H3 - Section Headers):**Medium, 18pt.
- **Body Text:** Regular, 16pt.
- **Small Text/Captions:** Regular, 14pt.

**Sizes (Common UI Elements):**

- **Icon Size:** 24px, 32px (for larger alerts).
- **Button Height:** 48px or 56px for touch targets.
- **Card Corner Radius:** 8px (slightly rounded for a modern feel).

**Spaces (Padding & Margins):**

- **Small (S):** 8dp (e.g., between icons and text).
- **Medium (M):** 16dp (e.g., standard padding, spacing between list items).
- **Large (L):** 24dp (e.g., section spacing, major content blocks).
- **Extra Large (XL):** 32dp (e.g., screen edge padding).
